# Midterm Map 2026

Tap-to-flip prediction maps for the Nov. 3, 2026 midterms: Senate, House, and NYC & Orange County races, with seat-holder, ballot and polling layers.

- Picks save in your own browser. There are 11 maps per device: Main plus 10 player slots.
- To compare with friends, copy a share code and send it. They paste it into the Share panel to load your map.
- Candidate lists and polls are current as of Nov. 2, 2026.

Live page: https://bindersfolder.github.io/midterm-map-2026/
